# GraphERM
An open-source, multi-scale computational physics platform for modeling macromolecular systems as coupled Quantum-Classical Edge Operating Systems. Tracks non-equilibrium phase boundaries, sub-structural molecular orbital splitting in hydrogen-bonding loops, and proton-coupled electron transport across \(5\text{Å}\) connectivity thresholds. Scales natively to model intracellular macromolecular crowding, map epistatic attractors in spatial multiomics datasets, and decode the distributed leader-cell election loops that steer collective multicellular tissue wavefronts.
